## 로봇의 구성

조종하는 로봇은 **세 개의 몸체 부품** — **헤드**, **차체**, 그리고 **다리** 세트 — 그리고 **화물 컨테이너**로 조립됩니다. 각 부품은 로봇의 스탯(코어,
CPU, 파워 그리드, 방어력, 속도, …)에 기여하고 **모듈 슬롯**을 제공합니다. 모듈은 해당 슬롯을 가진 부품의
슬롯에 장착됩니다. 모듈은 해당 모듈 자체의 플래그를 포함하는 카테고리 플래그를 가진 슬롯에만 장착할 수
있습니다(참고: [슬롯 카테고리](/ko/features/fitting/#seulros-kategori)).

개별 부품(헤드, 차체, 다리, 컨테이너)은 각각 자체 아이템 페이지가 있습니다(검색을 통해 찾거나, 해당 부품이
포함된 [레시피](/content/recipes/)에서 찾을 수 있습니다). 대부분의 모델은 두
**세대**로 제공됩니다 — 기본 모델과 개선된 **MK2** — 일부는 한정판 또는 이벤트 모델입니다.

## 활성 로봇

- **활성 로봇 선택** — 조종할 로봇을 선택합니다. 요구 사항:
  - **도킹** 상태여야 합니다,
  - 로봇이 소유한 컨테이너에 있어야 합니다(코퍼레이션 격납고, 로봇 인벤토리, 시스템 컨테이너 제외),
  - 로봇이 **단품 상태이며 언패킹**되어 있어야 합니다(재포장되지 않음),
  - 해당 로봇 클래스의 **활성화 확장**을 연구했어야 합니다
    (참고: [연구](/ko/features/research/)).
- 캐릭터당 **하나**의 로봇만 활성 로봇이 될 수 있으며, 하나의 로봇이 동시에 두 캐릭터의
  활성 로봇이 될 수 없습니다.
- **로봇 비우기** — 로봇에서 모든 것을 내립니다.
- **로봇 정보 / 피팅 정보** — 구성 부품, 모듈, 탄약, 파생 스탯을 확인합니다.
- **틴트 설정** — 로봇의 외관용 색상입니다.

## 슬롯 카테고리

로봇의 구성 부품(헤드, 차체, 다리)은 **슬롯**을 제공하며, 각 슬롯은 카테고리 플래그 세트를
가집니다. 모듈은 모듈 자체의 플래그가 슬롯 플래그의 **부분 집합**인 경우에만 해당 슬롯에
장착할 수 있습니다. 플래그 카테고리는 다음과 같습니다:

`small`, `medium`, `large`, `turret`, `missile`, `melee`, `industrial`,
`ew_and_engineering`, `specialized` (특수화 슬롯은 특수화 모듈만 수용합니다),
그리고 구조적 `head` / `chassis` / `leg` 슬롯.

모듈은 특정 로봇으로 제한될 수도 있으며, 일부는 **unique** 플래그를 가져
해당 유형의 모듈은 동시에 하나만 장착할 수 있습니다. 모듈별 스탯 효과는 자동 생성된
[로봇 테이블](/content/robots/)에 있습니다.
