# 소셜

이 페이지는 소통과 평판을 다룹니다: **메일**, **채팅 채널**, **친구**,
**스탠딩**, 그리고 공개 **옐로 페이지 / 뉴스 / 투표**.

> UI 위치는 [클라이언트 UI 개요](/ko/features/ui/)를 따릅니다(왼쪽 위 **메일** 버튼; 채팅과
> 소셜은 각각 자체 창을 가짐). 아래 메커니즘은 서버 기준으로 확인되었습니다.

## 메일

**개인 메일:**
- 메일 **목록 보기**, 메시지 **열기**, 메일 **보내기**, 메시지 **삭제**.
- **새 메시지 수** — 읽지 않은 메시지 수.
- **폴더** — **사용 중인 폴더** 보기, 메시지를 폴더로 **이동**, 폴더 **삭제**.

**대량 메일(코퍼레이션):** 코퍼레이션 전체에 전송:
- **보내기**, **목록 보기**, **열기**, **삭제**, **새 메시지 수**.

## 채팅 채널

**채널**은 이름이 지정된 채팅방입니다:

- 채널 **만들기**, 채널 **가입하기**, 채널 **나가기**, 채널에서 **대화하기**.
- 채널 **목록 보기**(전체 또는 내 채널만).
- **관리**(채널 소유자/임원으로서): **추방**, **BAN** / **BAN 해제**, **멤버 역할 설정**, **전체 음소거**, **음소거** / **BAN**된 멤버 보기.
- **설정**: **비밀번호 설정**, **토픽 설정**, **알림** 설정.

**다이렉트 채팅** — 캐릭터 간 개인 메시지.

## 친구

- **친구 요청 보내기**, 요청에 **답장하기**, 대기 중인 요청 **확인하기**.
- 친구 **삭제하기**, 캐릭터 **차단하기**.
- 내 친구 **목록 보기**.

캐릭터를 차단하면 해당 캐릭터가 나에게 거래/메시지를 보낼 수 없게 됩니다(캐릭터별 거래 차단은 [시작하기](/ko/features/getting-started/) 참고).

## 스탠딩(평판)

**스탠딩**은 엔티티(캐릭터, 코퍼레이션, 얼라이언스) 간의 수치형 평판입니다:

- 내 스탠딩 **목록 보기**, **스탠딩 이력** 보기.
- **스탠딩 설정** — 허용되는 경우 스탠딩 값을 설정합니다. 제약 조건:
  - **대상**은 캐릭터, (비공개) 코퍼레이션, 또는 (비공개) 얼라이언스여야 합니다,
  - **출처**도 마찬가지로 유효한 엔티티여야 합니다,
  - 자신에게 스탠딩을 설정할 수 없습니다.
- **기본 스탠딩** — 기본 얼라이언스/코퍼레이션의 기준 스탠딩.

스탠딩은 **-10에서 +10**까지의 값입니다(0 = 중립, 기본값; 0으로 설정하면 항목이 삭제됩니다). 엔티티의 **평판**은 모든 엔티티가 해당 엔티티에 대해 가진 스탠딩의 합산입니다.
양의 스탠딩은 구체적인 상황에서 중요합니다. 예를 들어 [침투](/ko/features/intrusion/)
중 상호 스탠딩이 10 이상인 코퍼레이션은 **동맹**으로 간주되며, 해당 코퍼레이션의 SAP 승리가 내 사이트를 손상시키지 않습니다.

스탠딩은 팩션과 다른 플레이어가 나와 내 코퍼레이션을 대하는 방식에 영향을 줍니다([그룹](/ko/features/groups/) 참고).

## 옐로 페이지

공개 디렉터리(코퍼레이션 운영 목록):
- 목록 **조회하기**, 목록 **제출하기**, 목록 **삭제하기**, 디렉터리 **검색하기**.

## 뉴스 & 투표

- **뉴스** — **카테고리**와 **뉴스 목록** 보기; 읽지 않은 항목의 **새 항목 수**.
- **투표** — 투표 **보기** 및 **응답하기**.

## 실무 참고

- **메일과 채팅** — 메일은 영구적이고 개인적이며, 채널은 실시간 그룹방입니다.
- **대량 메일은 코퍼레이션 도구** — 임원이 멤버들에게 방송하는 데 사용합니다.
- **스탠딩은 방향성이 있음** — A의 B에 대한 스탠딩과 B의 A에 대한 스탠딩은 별개이며,
  내 코퍼레이션을 따릅니다.
- **차단은 내 방패** — 스팸러나 적대적 거래자를 차단하세요.
- **채널은 잠금 가능** — 비밀번호와 역할이 가입/대화 권한을 제한합니다.
