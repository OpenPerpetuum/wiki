# 클라이언트 및 PC 설정

Perpetuum 클라이언트를 실행하기 위한 실용적인 안내입니다.

## 먼저 규칙

멀티박싱(여러 클라이언트로 여러 캐릭터를 조작하는 것)은 **제한 범위 내에서** 허용됩니다.
시도하기 전에 알아야 할 페어플레이 규칙:

- **자동화 또는 멀티클라이언트 제어 소프트웨어 금지** — 항상.
- **동시에 활성 상태인 계정은 5개까지.**
- 가짜, 유효하지 않거나 도달할 수 없는 이메일 주소로 등록된 계정 금지 —
  해당 주소는 본인이 소유한 주소여야 합니다.

위반 시 즉시 영구 BAN이 될 수 있습니다.

## Windows: 여러 클라이언트

1. Perpetuum Steam 클라이언트를 설치합니다.
2. 게임 폴더에 `steam_appid.txt`가 있고 내용이
   `223410`인지 확인합니다.
3. 추가 클라이언트마다 `Perpetuum` 폴더 전체를 한 번씩 복사합니다.
4. 각 복사본에서 `Perpetuum.exe`를 실행합니다(선택적으로 복사본을 Steam에
   비-Steam 게임으로 추가할 수 있습니다).

**디스크 공간:** `Layers.gbf`와 `Perpetuum.gbf`는 크기가 크고 모든 복사본에서
동일합니다 — 한 번만 저장되도록 심볼릭 링크(`mklink`) 또는 바로가기를 만드세요.

## Linux: 여러 클라이언트

각 클라이언트 복사본에는 **서로 다른 Proton 버전**이 필요하며, 그렇지 않으면 실행을 거부합니다:

1. Steam과 Perpetuum을 평소처럼 설치하고 `steam_appid.txt`(`223410`)를 확인합니다.
2. 클라이언트마다 `Perpetuum` 폴더를 복사합니다.
3. Steam에 로그인한 상태에서 최근 Proton 버전을 여러 개 설치합니다(Steam을 통해,
   수동으로, 또는 GloriousEggroll 빌드를 사용).
4. 각 복사본을 해당 `Perpetuum.exe`를 가리키도록 Steam에 비-Steam 게임으로 추가합니다.
5. 각 복사본의 시작 옵션에서 **서로 다른 Proton 버전**을 지정합니다.
6. 먼저 실제 Steam 앱을 시작하고, 그 다음 복사본을 실행합니다.

문제 해결:

- Proton 버전을 선택하는 것만으로는 **설치되지 않습니다** — 선택한 버전으로
  게임을 한 번 실행해야 합니다.
- 실제 Steam 앱이 시작되지 않으면 먼저 Safe mode에서 시작합니다.
- Proton 5.0부터 DirectX 9/12 에뮬레이션은 **Vulkan**에서 실행됩니다.
  Vulkan 지원 GPU가 없다면 각 복사본의 시작 옵션에
  `PROTON_USE_WINED3D=1 %command%`를 추가하세요.
- 빨간 경고와 함께 빈 텍스트 상자: `libfreetype6:i386`을 설치하세요
  (Debian/Ubuntu 기반 배포판).

## UI 확대/축소

클라이언트는 고정 픽셀 UI를 사용하며 동적 확대/축소를 지원하지 않습니다. 우회 방법:

- **저해상도 전체 화면** — 디스플레이보다 낮은 해상도로 전체 화면을 설정하고 UI가
  화면을 채우도록 늘리게 합니다(창 모드와 경계 없는 모드는 항상 네이티브 해상도를
  사용합니다). 디스플레이 자체의 해상도를 낮추면 같은 효과를 냅니다.
- **UI 스케일러 앱** — 예: Lossless Scaler(Steam, Windows): 클라이언트를 기본
  크기로 창 모드로 실행하고, 스케일러에서 사용자 지정 확대 비율을 설정한 뒤
  확대를 트리거하고 클라이언트 창에 포커스를 맞춥니다. 일반적인 부드러움과 텍스트
  선명도 사이의 트레이드오프를 예상하세요.
- **OS 확대기** — 가끔 가깝게 자세히 보기 위해 Windows Magnifier(또는 동등한 기능)를
  사용합니다.

## 관리자 권한 없이 시작하기

1. 클라이언트 파일을 Steam 폴더에서 쓸 수 있는 위치로 복사합니다.
2. 해당 위치에 `Perpetuum.bat`를 만들고 다음 내용을 포함합니다.
   `cmd /min /C "set __COMPAT_LAYER=RUNASINVOKER && start Perpetuum.exe"`.
3. 배치 파일을 통해 실행합니다.
