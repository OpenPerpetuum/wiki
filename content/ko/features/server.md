# 서버 및 참조

이 페이지는 "메타" 시스템을 다룹니다: 서버/시스템 정보, 최고 기록, 클라이언트가 다운로드하는
참조 데이터, 그리고 게임 내 스토어.

> UI 위치는 [클라이언트 UI 개요](/ko/features/ui/)를 따릅니다. 아래 메커니즘은 서버와 대조하여 확인했습니다.

## 서버 및 시스템 정보

- **서버 정보** — 일반적인 서버 상태/정보.
- **시스템 정보** — 시스템 수준의 세부 정보.
- **서버 종료 상태** — 예약된 종료가 적용 중인지 여부(플레이어는 읽기 전용;
  종료 자체는 관리자 작업).

## 최고 기록

- **서버 최고 기록** — 서버 전체의 상위 기록.
- **내 최고 기록** — 개인 최고 기록.

또한 [전투](/ko/features/combat/)에서 처치가 이 기록에 반영되는 방식을 참조하세요.

## 참조 데이터

클라이언트는 콘텐츠를 올바르게 렌더링하기 위해 서버에서 정적 참조 데이터를 다운로드합니다.
이들은 **읽기 전용 조회**이며, 플레이어 동작이 아닙니다:

- **이펙트** — 이펙트 정의.
- **열거형** — 열거형 값.
- **엔티티 기본값** — 엔티티의 기본 정의.
- **집계 필드** — 집계된 필드 데이터.
- **정의 설정 단위** — 정의별 설정.
- **거리** — 클라이언트가 사용하는 거리 상수.
- **명령** — 알려진 명령 목록(클라이언트 측 참조).
- **리프트** — 리프트 정의(또한 구역 리프트 목록 참조).

이들을 "사용"하는 것이 아닙니다. 클라이언트가 필요할 때 가져옵니다. 명령 인벤토리에
표시되기 때문에 여기에 나열되어 있습니다.

## 스토어

게임 내 스토어(결제 통합):

- **제품 목록 보기** — 판매 중인 항목 확인.
- **거래 시작** — 구매 시작.
- **거래 완료** — 구매 완료.

스토어 구매는 실제 화폐(또는 동등한 가치) 거래이며, 정확한 제품과
가격은 스토어 콘텐츠입니다.

## 실무 참고 사항

- **참조 데이터는 자동으로 가져옵니다** — 수동으로 트리거하지 않으며, 클라이언트를
  서버 콘텐츠와 동기화합니다.
- **최고 기록은 자랑할 권리입니다** — 개인 최고 기록과 서버 기록을 확인하세요.
- **스토어 거래는 2단계입니다** — 시작 후 완료; 완료될 때까지 구매가
  끝났다고 가정하지 마세요.
- **종료 상태는 정보 제공용입니다** — 유지보수 시간이 다가오는지 알려줍니다.
