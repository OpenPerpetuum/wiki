# 형식

개발자용 필드 참고 자료입니다. 각 페이지는 스탯 필드가 저장 위치(DB 컬럼, 규칙 파일 키, 또는 바이너리 레이어 바이트)에서 해당 값을 소비하는 코드를 거쳐 어떻게 사용되는지 추적하며, 구체적인 수치 예제를 함께 제공합니다. 플레이어 대상 "게임 내 의미" 요약은 [기능](/ko/features/)과 [콘텐츠](/content/) 섹션에 있으며, 여기서는 정확한 타입, 기본값, 공식, 코드 경로를 다룹니다.

| 페이지 | 내용 |
|---|---|
| [식물 필드](/ko/formats/plant-fields/) | 식물 규칙 파일 형식(GenXY), 타입/기본값/소비 코드를 포함한 모든 규칙 필드, 성장 상태 머신, 검증 검사 |
| [광물 필드](/ko/formats/ore-fields/) | `minerals` + `mineralconfigs` 컬럼, 노드 생성 공식, 노드 수명 주기 및 영속성, 추출 메커니즘 |
| [배치 가능 필드](/ko/formats/deployable-fields/) | 배치 가능 객체 식별 방식, 캡슐↔객체 페어링, 배치된 객체를 제어하는 집계 필드 |
| [구역 파일](/ko/formats/zone-files/) | 바이너리 지형 레이어 파일: 구조체 레이아웃, 플래그 비트, 저장 주기, 대신 DB에 저장되는 항목 |

규약:

- **GenXY**는 규칙 파일과 `entitydefaults.options`에 사용되는 설정 직렬화 형식입니다.
  (`GenxyToken.cs`의 토큰 문자 기준; [식물 필드 → 파일 형식](/ko/formats/plant-fields/) 참고).
- 코드 경로는 `src/` 기준입니다.
- 값이 **상수**(데이터가 아닌)인 경우, 해당 파일과 상수 이름을 명시합니다.
