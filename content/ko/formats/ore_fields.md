# 광물 필드

광물은 데이터베이스의 종으로 정의됩니다.

## 데이터 필드

| 필드 | 유형 | 설명 |
|---|---|---|
| `definition` | int | 정의 ID |
| `definitionname` | string | 정의 이름 |
| `type` | string | 광물 유형(고체, 액체) |
| `charge` | # | 광물 전하(밀도) |
| `mass` | # | 광물 질량 |
| `value` | # | 광물 가치 |
