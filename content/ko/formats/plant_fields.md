# 식물 필드

식물 행동은 각 종에 대해 **규칙 파일**(プレーンテキスト)로 정의됩니다. `$GameRoot/plantrules/` 에 배치.

## 파일 형식

1줄당 1개의 `key=value`; `//` 스타일 주석은 제거. 값은 **GenXY 토큰 문자** 사용(`GenxyReader.cs`):

| 토큰 | 파싱 결과 | 예 |
|---|---|---|
| `#` | 10진 정수 | `#100` = 100 |
| `.` | 부동소수점 | `.5` = 0.5 |
| `s
