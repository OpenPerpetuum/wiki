# コンテンツ

全コンテンツエンティティのステータス表。ライブデータベースから生成されます。

| Page | Contents |
|---|---|
| [Ores](/ja/content/ores/) | All ore types and extraction yields; per-zone node parameters on each ore page |
| [Plants](/ja/content/plants/) | Every plant species rule (growRate, fertility, spreading, fruit), per-zone fertility |
| [Deployables](/ja/content/deployables/) | Deployable structures and placeables with stats |
| [Robots](/ja/content/robots/) | Every robot by class and generation, with strengths and weaknesses |
| [Extensions](/ja/content/extensions/) | Full extension (skill) tree: rank, price, bonus, prerequisites |
| [Tech tree](/ja/content/techtree/) | Every tech tree node: unlocked item, enabler extension, point prices |
| [Missions](/ja/content/missions/) | All missions: type, level, duration, reward fee, reward items |
| [Item shop](/ja/content/shop/) | Vendor catalog per shop location and item category, with the price in every currency |
| [Recipes](/ja/content/recipes/) | Every craftable item and its components, research level |
