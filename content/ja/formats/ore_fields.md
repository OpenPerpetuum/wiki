# 鉱石フィールド

鉱石はデータベース内の種で定義されます。

## データフィールド

| フィールド | 型 | 説明 |
|---|---|---|
| `definition` | int | 定義ID |
| `definitionname` | string | 定義名 |
| `type` | string | 鉱石タイプ（固体、液体） |
| `charge` | # | 鉱石チャージ（密度） |
| `mass` | # | 鉱石質量 |
| `value` | # | 鉱石価値 |
