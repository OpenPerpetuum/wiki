# フォーマット

開発者向けのフィールドリファレンスです。各ページでは、ステータスフィールドの保存先
（DBカラム、ルールファイルのキー、バイナリレイヤーのバイト）から、それを消費するコードまでを
追跡し、数値の具体例を交えて説明します。プレイヤー向けの「ゲーム内で何を意味するか」の要約は
[機能](/ja/features/) と [コンテンツ](/content/) セクションにあります。ここでは、正確な型、
デフォルト値、数式、コードパスを扱います。

| ページ | 内容 |
|---|---|
| [植物フィールド](/ja/formats/plant-fields/) | 植物ルールファイルの形式（GenXY）、型/デフォルト値/使用箇所を備えたすべてのルールフィールド、成長ステートマシン、検証チェック |
| [鉱石フィールド](/ja/formats/ore-fields/) | `minerals` + `mineralconfigs` カラム、ノード生成の数式、ノードのライフサイクルと永続化、採掘メカニクス |
| [設置可能オブジェクトフィールド](/ja/formats/deployable-fields/) | 設置可能オブジェクトの識別方法、カプセル↔オブジェクトのペアリング、配置済みオブジェクトを駆動する集約フィールド |
| [ゾーンファイル](/ja/formats/zone-files/) | バイナリ地形レイヤーファイル：構造体のレイアウト、フラグビット、保存サイクル、DBに保存される項目 |

規約：

- **GenXY** はルールファイルと `entitydefaults.options` に使用される設定シリアライズです
  （トークン文字は `GenxyToken.cs` に従います。[植物フィールド → ファイル形式](/ja/formats/plant-fields/) を参照）。
- コードパスは `src/` からの相対パスです。
- 値が**定数**（データではない）である場合、ファイル名と定数名を記載します。
