# サーバーと参照情報

このページでは「メタ」システム、すなわちサーバー/システム情報、ハイスコア、クライアントがダウンロードする参照データ、ゲーム内ストアについて説明します。

> UI の場所は [クライアント UI 概要](/ja/features/ui/) に従います。以下の仕組みはサーバー側で確認済みです。

## サーバーとシステム情報

- **サーバー情報** — サーバーの一般的な状態/情報。
- **システム情報** — システムレベルの詳細。
- **サーバー停止状態** — 予定停止が有効かどうか（プレイヤーは読み取り専用。停止自体は管理者操作）。

## ハイスコア

- **サーバーハイスコア** — サーバー全体の上位成績。
- **マイハイスコア** — 自分のベスト記録。

[戦闘](/ja/features/combat/) も参照してください。キルがどのようにこれらのスコアに反映されるかを説明しています。

## 参照データ

クライアントは、コンテンツを正しく描画するためにサーバーから静的な参照データをダウンロードします。
これらは **読み取り専用の参照** であり、プレイヤーの操作ではありません：

- **エフェクト** — エフェクトの定義。
- **列挙型** — 列挙値。
- **エンティティのデフォルト** — エンティティのベース定義。
- **集約フィールド** — 集約されたフィールドデータ。
- **定義設定ユニット** — 定義ごとの設定。
- **距離** — クライアントで使用される距離定数。
- **コマンド** — 既知のコマンドの一覧（クライアント側の参照）。
- **リフト** — リフトの定義（ゾーンのリフト一覧も参照）。

これらはプレイヤーが「使用する」ものではなく、クライアントが必要に応じて取得します。コマンドインベントリに表示されるため、ここに記載しています。

## ストア

ゲーム内ストア（決済連携）：

- **商品一覧** — 販売中の商品を確認します。
- **取引の開始** — 購入を開始します。
- **取引の完了** — 購入を完了します。

ストアでの購入は実在のお金（または同等の価値）による取引です。具体的な商品や価格はストアのコンテンツとして扱われます。

## 実用上の注意点

- **参照データは自動取得されます** — 手動でトリガーすることはありません。クライアントをサーバーのコンテンツと同期させます。
- **ハイスコアは自慢の材料です** — 自分のベスト記録とサーバー全体の記録を確認できます。
- **ストアの取引は 2 段階です** — 開始してから完了します。完了するまで購入が確定したと仮定しないでください。
- **停止状態は情報提供です** — メンテナンスウィンドウが近づいているかどうかを知らせます。
