# FAQ

## 無料ですか？

はい。Open Perpetuum は**無料でプレイ**できます。ゲーム内ショップで便利さを購入できますが、プレイには必須ではありません。

## Linux で動きますか？

はい。クライアントは Windows のみですが、Steam の **Proton** で正常に動作します。

## PvP はありますか？

あります。ガンマゾーンは**オープン PvP** です。アルファゾーンは**PvE**（プレイヤーに対して安全）。ベータゾーンは**制限付き PvP** です。
