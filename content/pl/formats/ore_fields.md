# Pola rud

Rudy są definiowane według gatunków w bazie danych.

## Pola danych

| Pole | Typ | Opis |
|---|---|---|
| `definition` | int | ID definicji |
| `definitionname` | string | Nazwa definicji |
| `type` | string | Typ rudy (stała, płynna) |
| `charge` | # | Ładunek rudy (gęstość) |
| `mass` | # | Masa rudy |
| `value` | # | Wartość rudy |
