# Zawartość

Tabele statów dla każdej encji zawartości, wygenerowane z aktywnej bazy danych.

| Page | Contents |
|---|---|
| [Ores](/pl/content/ores/) | All ore types and extraction yields; per-zone node parameters on each ore page |
| [Plants](/pl/content/plants/) | Every plant species rule (growRate, fertility, spreading, fruit), per-zone fertility |
| [Deployables](/pl/content/deployables/) | Deployable structures and placeables with stats |
| [Robots](/pl/content/robots/) | Every robot by class and generation, with strengths and weaknesses |
| [Extensions](/pl/content/extensions/) | Full extension (skill) tree: rank, price, bonus, prerequisites |
| [Tech tree](/pl/content/techtree/) | Every tech tree node: unlocked item, enabler extension, point prices |
| [Missions](/pl/content/missions/) | All missions: type, level, duration, reward fee, reward items |
| [Item shop](/pl/content/shop/) | Vendor catalog per shop location and item category, with the price in every currency |
| [Recipes](/pl/content/recipes/) | Every craftable item and its components, research level |

Znaczenia pól (co kolumna statów tak naprawdę robi) są w [Formats](/pl/formats/).
