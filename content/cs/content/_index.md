# Obsah

Tabulky statistik pro každou obsahovou entitu, generované z živé databáze.

| Page | Contents |
|---|---|
| [Ores](/cs/content/ores/) | All ore types and extraction yields; per-zone node parameters on each ore page |
| [Plants](/cs/content/plants/) | Every plant species rule (growRate, fertility, spreading, fruit), per-zone fertility |
| [Deployables](/cs/content/deployables/) | Deployable structures and placeables with stats |
| [Robots](/cs/content/robots/) | Every robot by class and generation, with strengths and weaknesses |
| [Extensions](/cs/content/extensions/) | Full extension (skill) tree: rank, price, bonus, prerequisites |
| [Tech tree](/cs/content/techtree/) | Every tech tree node: unlocked item, enabler extension, point prices |
| [Missions](/cs/content/missions/) | All missions: type, level, duration, reward fee, reward items |
| [Item shop](/cs/content/shop/) | Vendor catalog per shop location and item category, with the price in every currency |
| [Recipes](/cs/content/recipes/) | Every craftable item and its components, research level |

Významy polí (co sloupec statistiky ve skutečnosti dělá) jsou v [Formats](/cs/formats/).
