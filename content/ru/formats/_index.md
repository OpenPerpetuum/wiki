# Форматы

Справочник по полям для разработчиков. Каждая страница отслеживает поле параметров от места его хранения (колонка БД, ключ в файле правил или байт двоичного слоя) через обрабатывающий его код с практическими числовыми примерами. Описания для игроков («что это значит в игре») находятся в разделах [возможности](/ru/features/) и [контент](/content/) — здесь же приведены точные типы, значения по умолчанию, формулы и пути в кодовой базе.

| Страница | Содержимое |
|---|---|
| [Поля растений](/ru/formats/plant-fields/) | Формат файлов правил растений (GenXY), каждое поле правил с типом/значением по умолчанию/потребителем, конечный автомат роста, проверки валидации |
| [Поля руды](/ru/formats/ore-fields/) | Колонки `minerals` + `mineralconfigs`, формулы генерации жил, жизненный цикл и сохранение жил, механика добычи |
| [Поля развертываемых объектов](/ru/formats/deployable-fields/) | Идентификация развертываемых объектов, связывание капсулы и объекта (capsule↔object), а также составные поля, управляющие установленными объектами |
| [Файлы зон](/ru/formats/zone-files/) | Файлы двоичных слоев рельефа: структура данных, битовые флаги, цикл сохранения и то, что вместо этого хранится в БД |

Соглашения:

- **GenXY** — это формат сериализации настроек, используемый для файлов правил и `entitydefaults.options` (символы токенов согласно `GenxyToken.cs`; см. [Поля растений → формат файла](/ru/formats/plant-fields/)).
- Пути к коду указаны относительно `src/`.
- Если значение является **константой** (а не данными), указываются файл и имя константы.
