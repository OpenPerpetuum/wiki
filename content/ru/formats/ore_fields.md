# Поля руды

Руда определяется по видам в базе данных.

## Поля данных

| Поле | Тип | Описание |
|---|---|---|
| `definition` | int | ID определения |
| `definitionname` | string | Имя определения |
| `type` | string | Тип руды (твёрдая, жидкая) |
| `charge` | # | Заряд руды (плотность) |
| `mass` | # | Масса руды |
| `value` | # | Ценность руды |
