# Поля растений

Поведение растений определяется для каждого вида **файлом правил**
(обычный текст) под `$GameRoot/plantrules/`.

## Формат файла

Одна `key=value` на строку; комментарии в стиле `//` удаляются. Значения
используют **символы токенов GenXY** (`GenxyReader.cs`):

| Токен | Разбирается как | Пример |
|---|---|---|
| `#` | Целое число в десятичной системе | `#100` = 100 |
| `.` | Число с плавающей точкой | `.5` = 0.5 |
| `s` | Строка | `sHello` |
| `b` | Булево | `b1` = true |
| `c` | Символ | `cA` = 'A' |

## Поля правил

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `fertility` | # | 1 | Частота появления растения |

| `allowedWaterLevelLow` | # | 0 | Минимальное расстояние от берега |
| `allowedWaterLevelHigh` | # | 100 | Максимальное расстояние от берега |
