# Настройка клиента и ПК

Практические рекомендации по запуску клиента Perpetuum.

## Сначала о правилах

Мультибоксинг (запуск нескольких клиентов для управления несколькими персонажами) разрешён **с ограничениями**. Правила честной игры, о которых необходимо знать заранее:

- **Никакой автоматизации или ПО для одновременного управления несколькими клиентами** — категорически запрещено.
- **Не более 5 одновременно активных аккаунтов.**
- Запрещена регистрация аккаунтов на поддельные, недействительные или недоступные адреса электронной почты — вы должны являться владельцем используемого адреса.

Нарушение этих правил может повлечь за собой немедленный и бессрочный бан.

## Windows: запуск нескольких клиентов

1. Установите клиент Perpetuum через Steam.
2. Убедитесь, что в папке с игрой присутствует файл `steam_appid.txt` с содержимым `223410`.
3. Создайте копию всей папки `Perpetuum` для каждого дополнительного клиента.
4. Запускайте `Perpetuum.exe` из каждой копии (при желании можно добавить их в Steam как сторонние игры).

**Место на диске:** файлы `Layers.gbf` и `Perpetuum.gbf` имеют большой размер и идентичны в каждой копии — настройте их как символические ссылки (`mklink`) или ярлыки, чтобы они хранились на диске в единственном экземпляре.

## Linux: запуск нескольких клиентов

Каждой копии клиента требуется **отдельная версия Proton**, иначе игра откажется запускаться:

1. Установите Steam и Perpetuum стандартным способом; проверьте `steam_appid.txt` (`223410`).
2. Скопируйте папку `Perpetuum` для каждого клиента.
3. Не выходя из Steam, установите несколько актуальных версий Proton (через сам Steam, вручную или сборки GloriousEggroll).
4. Добавьте каждую копию в Steam как стороннюю игру, указав путь к соответствующему `Perpetuum.exe`.
5. В параметрах запуска каждой копии принудительно выберите **другую версию Proton**.
6. Сначала запустите основную версию игры из Steam, а затем — добавленные копии.

Решение возможных проблем:

- Выбор версии Proton **не** устанавливает её автоматически — игру необходимо запустить хотя бы один раз с выбранной версией.
- Если основное приложение Steam не запускается, попробуйте сначала запустить его в безопасном режиме (Safe mode).
- Начиная с Proton 5.0, эмуляция DirectX 9/12 выполняется через **Vulkan**. Если видеокарта не поддерживает Vulkan, добавьте `PROTON_USE_WINED3D=1 %command%` в параметры запуска каждой копии.
- Появляется пустое текстовое поле с красным предупреждением: установите пакет `libfreetype6:i386` (для дистрибутивов на базе Debian/Ubuntu).

## Масштабирование интерфейса

Клиент использует интерфейс с фиксированным разрешением в пикселях без динамического масштабирования. Способы решения:

- **Полноэкранный режим с пониженным разрешением** — переключитесь в полноэкранный режим с разрешением ниже, чем у вашего монитора, чтобы интерфейс растянулся на весь экран (в оконном режиме и режиме без рамок всегда используется нативное разрешение). Снижение разрешения самого экрана даёт аналогичный эффект.
- **Сторонние утилиты масштабирования** — например, Lossless Scaling (Steam, Windows): запустите клиент в оконном режиме в базовом разрешении, задайте желаемый масштаб в утилите, активируйте масштабирование и переключитесь на окно клиента. Учитывайте привычный компромисс между плавностью и чёткостью текста.
- **Экранная лупа ОС** — «Экранная лупа» Windows (или её аналог) для периодического чтения мелких элементов интерфейса.

## Запуск без прав администратора

1. Скопируйте файлы клиента из папки Steam в каталог, доступный для записи.
2. Создайте там файл `Perpetuum.bat` со следующим содержимым:  
   `cmd /min /C "set __COMPAT_LAYER=RUNASINVOKER && start Perpetuum.exe"`.
3. Запускайте игру через этот пакетный файл.
