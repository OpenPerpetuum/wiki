# Сервер и справочные данные

На этой странице описаны «мета»-системы: информация о сервере и системе, таблицы рекордов, справочные данные, загружаемые клиентом, и внутриигровой магазин.

> Расположение элементов интерфейса соответствует [обзору интерфейса клиента](/ru/features/ui/). Приведённые ниже механики проверены по исходному коду сервера.

## Информация о сервере и системе

- **Информация о сервере (Server info)** — общее состояние и сведения о сервере.
- **Информация о системе (System info)** — системные параметры и подробности.
- **Статус выключения сервера (Server shutdown state)** — действует ли запланированная перезагрузка или отключение (доступно только для чтения игрокам; само отключение выполняется администратором).

## Рекорды и таблицы лидеров

- **Рекорды сервера (Server high scores)** — лучшие результаты среди всех игроков сервера.
- **Мои рекорды (My high scores)** — ваши личные достижения.

См. также раздел [Бой](/ru/features/combat/) о том, как уничтожение противников учитывается в этой статистике.

## Справочные данные

Клиент загружает с сервера статические справочные данные для корректного отображения контента. Это **запросы только для чтения**, а не действия игрока:

- **Эффекты (Effects)** — определения эффектов.
- **Перечисления (Enums)** — значения перечислений (enum).
- **Параметры сущностей по умолчанию (Entity defaults)** — базовые определения сущностей.
- **Агрегированные поля (Aggregate fields)** — сводные данные полей характеристик.
- **Конфигурационные единицы определений (Definition config units)** — параметры конфигурации для каждого определения.
- **Дистанции (Distances)** — константы расстояний, используемые клиентом.
- **Команды (Commands)** — список поддерживаемых команд (клиентский справочник).
- **Разломы (Rifts)** — параметры разломов (см. также список разломов зоны).

Игроку не нужно запрашивать эти данные вручную: клиент запрашивает их по мере необходимости. Они приведены здесь, поскольку входят в общий реестр команд.

## Магазин

Внутриигровой магазин (интеграция платежей):

- **Список товаров (List products)** — просмотр доступных предложений.
- **Начало транзакции (Start a transaction)** — инициирование покупки.
- **Завершение транзакции (Finish a transaction)** — подтверждение и проведение покупки.

Покупки в магазине совершаются за реальные деньги (или их эквивалент); ассортимент и цены определяются контентом магазина.

## Практические заметки

- **Справочные данные загружаются автоматически** — вручную их запрашивать не требуется; благодаря этому клиент синхронизируется с базой сервера.
- **Таблицы лидеров показывают ваши достижения** — отслеживайте личные успехи и общие рекорды сервера.
- **Транзакции в магазине состоят из двух этапов** — запуск, затем подтверждение; покупка не считается совершенной до завершения второго этапа.
- **Статус отключения носит информационный характер** — предупреждает о скором начале технического обслуживания.
