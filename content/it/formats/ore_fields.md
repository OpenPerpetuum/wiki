# Campi dei minerali

I minerali sono definiti per specie nel database.

## Campi dati

| Campo | Tipo | Descrizione |
|---|---|---|
| `definition` | int | ID della definizione |
| `definitionname` | string | Nome della definizione |
| `type` | string | Tipo di minerale (solido, liquido) |
| `charge` | # | Carica del minerale (densità) |
| `mass` | # | Massa del minerale |
| `value` | # | Valore del minerale |
