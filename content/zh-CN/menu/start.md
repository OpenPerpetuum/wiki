# 入门

你在 Open Perpetuum 中的第一步：创建角色、获取帮助以及运行客户端。

- **[快速上手](/zh-CN/features/getting-started/)** — 创建角色、领取初始机器人以及角色基础。
- **[常见问题](/zh-CN/features/faq/)** — 解答游戏初期最常见的问题：教程、选择阵营、训练结束后该做什么——以及[术语](/zh-CN/features/faq/)（EP、NIC、CT、EWar）。
- **[世界观](/zh-CN/features/lore/)** — 背景设定：尼亚、尼亚人、辛迪加。
- **[客户端与电脑设置](/zh-CN/features/client-setup/)** — 在 Windows 和 Linux 上运行客户端、合规多开、UI 缩放以及启动设置。
