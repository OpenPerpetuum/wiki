# 矿石字段

矿石通过数据库中的物种定义。

## 数据字段

| 字段 | 类型 | 描述 |
|---|---|---|
| `definition` | int | 定义 ID |
| `definitionname` | string | 定义名称 |
| `type` | string | 矿石类型（固体、液体） |
| `charge` | # | 矿石电荷（密度） |
| `mass` | # | 矿石质量 |
| `value` | # | 矿石价值 |
