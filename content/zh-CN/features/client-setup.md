# 客户端与电脑设置

运行 Perpetuum 客户端的实用指南。

## 规则优先

多开（多个客户端控制多个角色）是**有限度**允许的。操作前请了解以下公平竞技规则：

- **禁止使用任何自动化或多客户端控制软件**——永远不要。
- **同时活跃的账户不得超过 5 个。**
- 不得使用虚假、无效或无法接收邮件的地址注册账户——该地址必须是你本人拥有的。

违规可能导致立即永久封禁。

## Windows：多开客户端

1. 安装 Perpetuum Steam 客户端。
2. 确认游戏文件夹中包含一个内容为 `223410` 的 `steam_appid.txt` 文件。
3. 每增加一个客户端，完整复制一次 `Perpetuum` 文件夹。
4. 在每个副本中运行 `Perpetuum.exe`（可选：将副本作为非 Steam 游戏添加到 Steam）。

**磁盘空间：** `Layers.gbf` 和 `Perpetuum.gbf` 文件体积较大且在每个副本中完全相同——请将其设为符号链接（`mklink`）或快捷方式，以便只存储一份。

## Linux：多开客户端

每个客户端副本需要使用**不同的 Proton 版本**，否则将拒绝运行：

1. 正常安装 Steam 和 Perpetuum；确认 `steam_appid.txt`（`223410`）。
2. 为每个客户端复制一份 `Perpetuum` 文件夹。
3. 在登录 Steam 的状态下，安装多个较新版本的 Proton（通过 Steam、手动安装或 GloriousEggroll 构建版）。
4. 将每个副本作为非 Steam 游戏添加到 Steam，指向其 `Perpetuum.exe`。
5. 在每个副本的启动选项中强制指定**不同的 Proton 版本**。
6. 先启动真正的 Steam 客户端，再启动各副本。

故障排除：

- 选择 Proton 版本**不会**自动安装它——你需要用该版本启动一次游戏。
- 如果真正的 Steam 客户端无法启动，请先以安全模式启动。
- 自 Proton 5.0 起，DirectX 9/12 模拟基于 **Vulkan** 运行。没有支持 Vulkan 的 GPU？请在每个副本的启动选项中添加 `PROTON_USE_WINED3D=1 %command%`。
- 出现带红色警告的空文本框：请安装 `libfreetype6:i386`（适用于基于 Debian/Ubuntu 的发行版）。

## UI 缩放

客户端使用固定像素的 UI，不支持动态缩放。替代方案：

- **低分辨率全屏**——以低于显示器原生分辨率的分辨率进入全屏模式，让 UI 拉伸填充整个屏幕（窗口模式和无边框模式始终使用原生分辨率）。降低显示器自身的分辨率也能达到相同效果。
- **UI 缩放工具**——例如 Lossless Scaler（Steam，Windows）：以基础分辨率窗口化运行客户端，在缩放工具中设置自定义缩放比例，触发缩放并聚焦客户端窗口。需接受平滑度与文字清晰度之间的常规取舍。
- **系统放大镜**——使用 Windows 放大镜（或等效工具）进行偶尔的近距离查看。

## 无需管理员权限启动

1. 将客户端文件从 Steam 文件夹复制到可写入的位置。
2. 在该位置创建一个 `Perpetuum.bat` 文件，内容为
   `cmd /min /C "set __COMPAT_LAYER=RUNASINVOKER && start Perpetuum.exe"`。
3. 通过批处理文件启动。
