# Leistungsbasisstationen (PBS)

**PBS** (Power Base Stations) sind Strukturen, die Corporations in Zonen
deployen, um das Terrain zu kontrollieren und Dienste bereitzustellen.

## Deployment

- Eine PBS wird von einer Corporation in einer Zone **deployed**.
- Das Deployment kostet **Gegenstände** (PBS-Kapseln) und **Zeit**.
- Eine PBS hat einen begrenzten **Wirkungsradius**.

## PBS-Typen

| Typ | Funktion |
|---|---|
| **Reaktor** | Versorgt andere PBS mit Energie |
| **Kontrollturm** | Zentralisiert die PBS der Zone |
| **Schmiede** | Ermöglicht Produktion |
| **Raffinerie** | Ermöglicht Raffination |
| **Mining-Turm** | Ermöglicht Mining |
| **Verteidigungsturm** | Verteidigt die PBS (Turrets) |
| **Energieknoten** | Verbindet PBS miteinander |
| **Prototypierer** | Ermöglicht die Erstellung von Prototypen |
| **Reprozessor** | Ermöglicht den Reprozessor |
| **Forschungslabor** | Ermöglicht Forschung |

## Verbindungen

- PBS müssen miteinander **verbunden** sein, um zu funktionieren.
- **Energieknoten** verbinden die PBS.
- Eine nicht verbundene PBS ist **offline**.

## Territorien

- Jede PBS hat ein **Territorium** (Wirkungsradius).
- Die Territorien der PBS einer Corporation **kombinieren** sich.
- Feindliche PBS **neutralisieren** sich gegenseitig in ihrem Wirkungsbereich.

## Effekte

PBS stellen **Effekte** für die Spieler der Corporation bereit:

- **Kostenlose Produktion** (an der Schmiede)
- **Kostenlose Raffination** (an der Raffinerie)
- **Beschleunigte Forschung** (im Labor)
- **Verteidigung** (Turrets des Verteidigungsturms)

## Versorgung

- PBS müssen mit **Energie versorgt** werden.
- Der **Reaktor** liefert die Bas
