# Transport

**Transport** ist das System zum Versenden von Gegenständen zwischen Basen.
Spieler stellen Container ein, damit andere Spieler sie zwischen Terminals
transportieren.

## So funktioniert's

1. **Reiche** einen Container bei einem Transportterminal ein.
2. Ein anderer Spieler **übernimmt** den Container.
3. Der Träger **liefert** den Container am Zielterminal ab.
4. der Auftraggeber **holt** den Container ab.
5. Der Träger erhält seine **Belohnung**.

## Belohnung & Sicherheit

- Der Auftraggeber definiert eine **Belohnung** (Credits) für den Träger.
- Der Träger setzt eine **Sicherheit**:
  - **Zurückgegeben**, wenn der Container unbeschädigt geliefert wird.
  - **Verloren**, wenn der Container zerstört wird.
  - **Die Hälfte zurückgegeben**, wenn der Träger unterwegs aufgibt.
- Halte die Container **klein** — jemand muss sie tragen können.

## Praktische Hinweise

- **Transport ist riskant** — die Routen sind gefährlich.
- **Die Sicherheit geht verloren**, wenn der Container zerstört wird.
- **Die Belohnungen müssen fair sein** — zu wenig und niemand übernimmt.
- **Begleite deine Container** — die Routen sind voller Piraten.
