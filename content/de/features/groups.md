# Gruppen

**Gruppen** sind die sozialen Strukturen des Spiels: Corporations, Allianzen,
und Gangs (Flotten).

## Corporations

Eine **Corporation** ist eine Gruppe von Spielern, die teilen:

- Einen gemeinsamen **Hangar** (geteilte Container)
- Eine gemeinsame **Kasse** (geteilte Credits)
- Geteilte **Dokumente**
- **Abstimmungen** für wichtige Entscheidungen

### Rollen

| Rolle | Berechtigungen |
|---|---|
| **Führer** | Alles (Corp verwalten, kicken, etc.) |
| **Offizier** | Hangar, Kasse, Dokumente verwalten |
| **Mitglied** | Corp-Einrichtungen nutzen |
| **Gast** | Begrenzter Zugriff (vom Führer definiert) |

### Mitgliedschaft

- Du kannst einer Corporation **beitreten** durch Einladung oder Anfrage.
- Du kannst jederzeit **austr

ten**.
- Der Führer kann ein Mitglied **kicken**.

## Allianzen

Eine **Allianz** ist eine Gruppe von Corporations, die zusammenarbeiten:

- Mitglieder der alliierten Corporations können leichter **interagieren**.
- Allianzen können **gemeinsame Ziele** haben.
- Allianzen werden von ihren Führern **verwaltet**.

## Gangs (Flotten)

Eine **Gang** (Fleet) ist eine Gruppe von Spielern, die zusammen unterwegs sind:

- Mitglieder einer Gang können bestimmte Aktionen **teilen**.
- Gangs sind **temporär** — sie lösen sich auf, wenn die Spieler sich trennen.
- Gangs sind nützlich für **Flottenkämpfe** und **begleitete Transporte**.

## Schwarzes Brett

Das **Schwarze Brett** ist ein Kommunikationsbereich:

- Spieler können **Nachrichten** posten.
- Nachrichten sind für alle Mitglieder **sichtbar**.
- Nachrichten können **kategorisiert** werden (Rekrutierung, Handel, etc.).

## Praktische Hinweise

- **Tritt einer Corporation bei** — es ist leichter in der Gruppe.
- **Gemeinsame Hangars** sind praktisch für die Lagerung.
- **Abstimmungen** sind für wichtige Entscheidungen.
- **Gangs sind temporär** — verlass dich nicht dauerhaft darauf.
