# Primeiros passos

## Instalar o cliente

1. Instale o [Steam](https://store.steampowered.com/) se não tiver.
2. Busque **Open Perpetuum** na Steam e instale.
3. No Linux, use Proton (funciona automaticamente).

## Criar um personagem

1. Faça login com sua conta.
2. Escolha um **nome de personagem** (único).
3. Escolha seu **spark inicial** (determina seus bônus passivos).
4. Seu personagem aparece em uma base de treinamento.
