# Grupos

Os **grupos** são as estruturas sociais do jogo: corporações, alianças, e gangs.

## Corporações

Uma **corporação** é um grupo de jogadores que compartilham:

- Um **hangar** comum
- Uma **caixa** comum (créditos)
- **Documentos** compartilhados
- **Votações** para decisões importantes
