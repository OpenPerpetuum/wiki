# Produção

A **produção** é o processo de transformar componentes em objetos.

## Linhas de produção

- Você deve estar **amarrado** para produzir.
- Cada linha tem um **tempo de produção**.
- Os componentes são **consumidos** ao final.

## Tipos

| Tipo | Descrição |
|---|---|
| **Montagem** | Combinar componentes em um objeto |
| **Refino** | Transformar minérios crus em materiais |
| **Reparo** | Reparar módulos danificados |
| **Reprocessador** | Extrair componentes de um objeto |
| **Protótipo** | Criar um protótipo de objeto |
