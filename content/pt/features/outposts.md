# Postos avançados & SAP

Os **postos avançados** são estruturas que as corporações tomam e mantêm nas
zonas PvP abertas.

## Estabilidade

- Cada posto tem uma **estabilidade** que varia de 0 a 100%.
- Os ataques inimigos **reduzem** a estabilidade.
- A estabilidade **regenera** com o tempo.
