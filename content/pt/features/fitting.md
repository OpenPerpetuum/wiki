# Equipamento

O **equipamento** (fitting) é o processo de carregar módulos nos slots do seu
robô. Tudo é feito **amarrado**.

## Slots

Cada robô tem um número limitado de **slots** de diferentes tipos:

| Tipo | Descrição |
|---|---|
| **Arma** | Slot para uma arma |
| **Defesa** | Slot para um módulo de defesa |
| **Energia** | Slot para um módulo de energia |
