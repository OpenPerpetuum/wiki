# Campos dos minerais

Os minerais são definidos por espécie na base de dados.

## Campos de dados

| Campo | Tipo | Descrição |
|---|---|---|
| `definition` | int | ID da definição |
| `definitionname` | string | Nome da definição |
| `type` | string | Tipo de mineral (sólido, líquido) |
| `charge` | # | Carga do mineral (densidade) |
| `mass` | # | Massa do mineral |
| `value` | # | Valor do mineral |
