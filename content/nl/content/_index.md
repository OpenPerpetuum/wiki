# Inhoud

Stat-tabellen voor elke inhoudsentiteit, gegenereerd uit de live-database.

| Page | Contents |
|---|---|
| [Ores](/nl/content/ores/) | All ore types and extraction yields; per-zone node parameters on each ore page |
| [Plants](/nl/content/plants/) | Every plant species rule (growRate, fertility, spreading, fruit), per-zone fertility |
| [Deployables](/nl/content/deployables/) | Deployable structures and placeables with stats |
| [Robots](/nl/content/robots/) | Every robot by class and generation, with strengths and weaknesses |
| [Extensions](/nl/content/extensions/) | Full extension (skill) tree: rank, price, bonus, prerequisites |
| [Tech tree](/nl/content/techtree/) | Every tech tree node: unlocked item, enabler extension, point prices |
| [Missions](/nl/content/missions/) | All missions: type, level, duration, reward fee, reward items |
| [Item shop](/nl/content/shop/) | Vendor catalog per shop location and item category, with the price in every currency |
| [Recipes](/nl/content/recipes/) | Every craftable item and its components, research level |
