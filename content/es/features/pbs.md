# Estaciones de base de poder (PBS)

Las **PBS** (Power Base Stations) son estructuras que las corporaciones despliegan
en las zonas para controlar el terreno y proporcionar servicios.

## Despliegue

- Una PBS se **despliega** por una corporación en una zona.
- El despliegue cuesta **objetos** (cápsulas PBS) y **tiempo**.
- Una PBS tiene un **radio de efecto** limitado.

## Tipos de PBS

| Tipo | Función |
|---|---|
| **Reactor** | Provee energía a otras PBS |
| **Torre de control** | Centraliza las PBS de la zona |
| **Forja** | Permite la producción |
| **Refinería** | Permite el refinado |
| **Torre de minería** | Permite la minería |
| **Torre de defensa** | Defiende la PBS (torretas) |
| **Nodo de energía** | Conecta las PBS entre sí |
| **Prototipador** | Permite crear prototipos |
| **Reprocesador** | Permite el reprocesador |
| **Laboratorio de investigación** | Permite la investigación |

## Conexiones

- Las PBS deben estar **conectadas** entre sí para funcionar.
- Los **nodos de energía** conectan las PBS.
- Una PBS no conectada está **fuera de línea**.

## Territorios

- Cada PBS tiene un **territorio** (radio de efecto).
- Los territorios de las PBS de una corporación se **combinan**.
- Las PBS enemigas se **neutralizan** mutuamente en su zona de efecto.

## Efectos

Las PBS proporcionan **efectos** a los jugadores de la corporación:

- **Producción gratis** (en la forja)
- **Refinado gratis** (en la refinería)
- **Investigación acelerada** (en el laboratorio)
- **Defensa** (torretas de la torre de defensa)

## Alimentación

- Las PBS deben estar **alimentadas** de energía.
- El **reactor** proporciona la energía base.
- Si una PBS no está alimentada, está **fuera de línea**.

## Torretas de defensa

Las **torretas** son torretas automáticas que defienden las PBS:

| Torreta | Tipo de daño |
|---|---|
| **PBS Turret** | Cinético |
| **PBS EW Turret** | EM (burla) |
| **PBS Laser Turret** | Térmico |
| **PBS Missile Turret** | Explosivo |
| **PBS Rail Turret** | Cinético (largo alcance) |
| **Police Guard Tower** | Defensa de zona |

## Notas prácticas

- **Las PBS son inversiones** — cuestan caro de desplegar.
- **La conexión es crucial** — una PBS no conectada es inútil.
- **Las torretas defienden** — pueden matar robots enemigos.
- **Los territorios se combinan** — cuantas más PBS, más zona controlada.
