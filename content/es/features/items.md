# Objetos & inventario

Tu **inventario** es donde almacenas tus objetos. Está organizado en **contenedores**
y **bolsas**.

## Contenedores

- Cada robot tiene un **contenedor** de capacidad limitada.
- Los contenedores de base (amarrado) tienen capacidad ilimitada.
- Puedes **renombrar** tus contenedores y bolsas.

## Bolsas y empaquetado

- Una **bolsa** es un objeto que contiene otros objetos.
- Las bolsas pueden **empaquetarse** para reducir su volumen.
- Los objetos **apilables** (municiones, minerales) se agrupan automáticamente.

## Objetos especiales

- **Canjeables** — objetos que puedes canjear por otros.
- **Packs de bienvenida** — objetos dados a nuevos jugadores.
- **Objetos de misión** — objetos vinculados a misiones.
- **Prototipos** — objetos que producen otros objetos gratis.

## Notas prácticas

- **Organiza tus contenedores** — nómbralos por categoría.
- **Empaqueta tus bolsas** — reduce el volumen.
- **No destruyas por accidente** — la destrucción es irreversible.
- **Los objetos apilables** se agrupan automáticamente.
