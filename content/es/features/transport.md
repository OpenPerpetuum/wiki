# Transporte

El **transporte** es el sistema de envío de objetos entre bases. Los jugadores
publican contenedores para que otros jugadores los transporten entre terminales.

## Cómo funciona

1. **Enviar** un contenedor a un terminal de transporte.
2. Otro jugador **toma** el contenedor.
3. El portador **entrega** el contenedor al terminal de destino.
4. El emisor **recupera** el contenedor.
5. El portador recibe su **recompensa**.

## Recompensas & caución

- El emisor define una **recompensa** (créditos) para el portador.
- El portador pone una **caución**:
  - **Devuelta** si el contenedor se entrega intacto.
  - **Perdida** si el contenedor es destruido.
  - **Mitad devuelta** si el portador abandona en el camino.
- Mantén los contenedores **pequeños** — alguien debe poder llevarlos.

## Notas prácticas

- **El transporte es riesgoso** — las rutas son peligrosas.
- **La caución se pierde** si el contenedor es destruido.
- **Las recompensas deben ser justas** — si son muy bajas, nadie toma.
- **Escorté tus contenedores** — las rutas están llenas de piratas.
