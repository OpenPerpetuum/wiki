# Servidor & referencia

Esta página da la información sobre el servidor y los recursos de referencia.

## Información del servidor

| Info | Valor |
|---|---|
| **Servidor** | Open Perpetuum (self-hosted) |
| **Base de datos** | SQL Server |
| **Cliente** | Steam (gratis) |
| **Plataformas** | Windows, Linux (Proton) |

## Puntuaciones altas

Las **puntuaciones altas** muestran los jugadores más destacados:

- Por **créditos**
- Por **NIC**
- Por **misiones completadas**
- Por **robots destruidos**

## Datos de referencia

Los **datos de referencia** están disponibles para descarga:

- [Recetas](/content/recipes/) — todas las recetas de producción
- [Minerales](/content/ores/) — todas las datos de minerales
- [Plantas](/content/plants/) — todas las datos de plantas
- [Misiones](/content/missions/) — todas las misiones
- [Tienda](/content/shop/) — el catálogo de la tienda

## Tienda in-game

La **tienda in-game** (IHS — In-game Store) es un sistema de compra con dinero real:

- **Packs de EP** — packs de Energy Points
- **Sparks** — sparks especiales
- **Tintes** — tintes exclusivos
- **Suscripciones** — suscripciones mensuales

> **Nota**: la tienda in-game es opcional. El juego es **completo sin compras**
> (free-to-play). El dinero real compra comodidad, no poder.

## Notas prácticas

- **El juego es gratis** — sin pay-to-win.
- **Los datos de referencia** son generados desde la base de datos.
- **Las puntuaciones** se actualizan en tiempo real.
- **La tienda** es opcional.
