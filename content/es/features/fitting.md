# Equipamiento

El **equipamiento** (fitting) es el proceso de cargar módulos en los espacios de tu
robot. Todo se hace **amarrado**.

## Espacios

Cada robot tiene un número limitado de **espacios** de diferentes tipos:

| Tipo | Descripción |
|---|---|
| **Arma** | Espacio para un arma |
| **Defensa** | Espacio para un módulo de defensa |
| **Energía** | Espacio para un módulo de energía |
| **Electrónica** | Espacio para un módulo electrónico |
| **EWar** | Espacio para un módulo de guerra electrónica |
| **EnWar** | Espacio para un módulo de guerra energética |
| **Industrial** | Espacio para un módulo industrial |
| **Navegación** | Espacio para un módulo de navegación |

## Cargar un módulo

1. Selecciona tu robot activo.
2. Abre la pantalla de equipamiento.
3. Arrastra un módulo desde tu inventario a un espacio compatible.
4. El módulo se **carga** — consume energía y espacio.

## Municiones

- Las **municiones** se cargan en los espacios de armas.
- Cada arma tiene un tipo de munición compatible.
- Las municiones se **consumen** al usarlas.

## Presets

Los **presets** son configuraciones guardadas:

- Puedes **guardar** tu equipamiento actual como preset.
- Puedes **aplicar** un preset para recargar rápidamente.
- Los presets son **por robot**.

## Tintes

- Los **tintes** son el color/pintura de tu robot.
- Son **cosméticos** — no cambian las stats.
- Puedes **comprar** tintes en la tienda o obtenerlos por misiones.

## Notas prácticas

- **Verifica la compatibilidad** — un módulo no puede ir en cualquier espacio.
- **La energía es limitada** — no sobrecargues tu reactor.
- **Los presets son tus amigos** — guarda tus configuraciones.
- **Las municiones cuestan** — no las desperdicies.
