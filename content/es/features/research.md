# Investigación

La **investigación** es el sistema de progresión del juego. Existen dos árboles:

## El árbol de extensiones (habilidades del personaje)

Las **extensiones** son habilidades pasivas que tu personaje aprende. Ellas
desbloquean:

- El uso de ciertas clases de robots
- Bonificaciones pasivas (daño, defensa, velocidad, etc.)
- Capacidades especiales (teletransporte, producción, etc.)

Cada extensión tiene un **costo en EP** y un **tiempo de aprendizaje**.

## El árbol tecnológico (desbloqueos)

El **árbol tecnológico** es un sistema de desbloqueo de objetos. Compras
**puntos de investigación** con **kernels**. Cada nodo desbloquea un objeto o
capacidad.

Las categorías del árbol tecnológico:

| Categoría | Descripción |
|---|---|
| **Nuimqol** | Investigación para la facción Nuimqol |
| **Pelistal** | Investigación para la facción Pelistal |
| **Thelodica** | Investigación para el clan Thelodica |
| **Común 1** | Módulos estándar (primer conjunto) |
| **Común 2** | Módulos estándar (segundo conjunto) |
| **PBS** | Estructuras de estación base |
| **Industrial** | Investigación industrial |

## Notas prácticas

- **Planifica tu investigación** — las extensiones y nodos son permanentes.
- **Los kernels son raros** — no los desperdicies.
- **La investigación es por personaje** — cada personaje tiene su propio árbol.
- **El árbol tecnológico es por corporación** — los nodos desbloquean objetos
  disponibles para toda la corporación.
