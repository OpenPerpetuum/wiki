# Robot

Tu **robot** es tu avatar en zona. Lo pilotas a distancia desde tu base.

## Seleccionar un robot activo

- Debes tener un **robot activo seleccionado** para desamarrar.
- El robot debe tener la **extensión de activación** requerida.
- Puedes **cambiar de robot** en cualquier momento (amarrado).

## Equipamiento (fitting)

El **equipamiento** es el proceso de cargar módulos en los espacios de tu robot.
Ver [Equipamiento](/es/features/fitting/) para detalles.

## Clases de robots

| Clase | Descripción |
|---|---|
| **Runner** | Rápido, ligero, poca armadura |
| **Crawler** | Pesado, lento, buena armadura |
| **Mech** | Equilibrado, bueno para combate |
| **Heavy Mech** | Muy pesado, muy armado, lento |
| **Walker** | El más pesado, el más armado |

## Gestión de robots

- **Listar tus robots** — ver todos los robots que posees.
- **Renombrar** — cambiar el nombre de un robot.
- **Destruir** — eliminar un robot (irreversible).
- **Transferir** — mover un robot de un personaje a otro.

## Notas prácticas

- **No engages lo que no puedes reemplazar** — un robot muerto está perdido.
- **Asegura tus robots caros** — la pérdida de un T4 es costosa.
- **Los presets son tus amigos** — guarda tus configuraciones.
- **Los tintes son cosméticos** — no cambian las stats.
