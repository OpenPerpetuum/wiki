# Stations de base de pouvoir (PBS)

Les **PBS** (Power Base Stations) sont des structures que les corporations déploient
dans les zones pour contrôler le terrain et fournir des services.

## Déploiement

- Une PBS est **déployée** par une corporation dans une zone.
- Le déploiement coûte des **objets** (capsules PBS) et du **temps**.
- Une PBS a un **rayon d'effet** limité.

## Types de PBS

| Type | Fonction |
|---|---|
| **Réacteur** | Fournit de l'énergie aux autres PBS |
| **Tour de contrôle** | Centralise les PBS de la zone |
| **Forge** | Permet la production |
| **Raffinerie** | Permet le raffinage |
| **Tour de minage** | Permet le minage |
| **Tour de défense** | Défend la PBS (turrets) |
| **Node d'énergie** | Connecte les PBS entre elles |
| **Prototyper** | Permet de créer des prototypes |
| **Reprocesseur** | Permet le reprocesseur |
| **Laboratoire de recherche** | Permet la recherche |

## Connexions

- Les PBS doivent être **connectées** entre elles pour fonctionner.
- Les **nodes d'énergie** connectent les PBS.
- Une PBS non connectée est **hors ligne**.

## Territoires

- Chaque PBS a un **territoire** (rayon d'effet).
- Les territoires des PBS d'une corporation se **combinent**.
- Les PBS ennemies **se neutralisent** mutuellement dans leur zone d'effet.

## Effets

Les PBS fournissent des **effets** aux joueurs de la corporation :

- **Production gratuite** (à la forge)
- **Raffinage gratuit** (à la raffinerie)
- **Recherche accélérée** (au laboratoire)
- **Défense** (turrets de la tour de défense)

## Alimentation

- Les PBS doivent être **alimentées** en énergie.
- Le **réacteur** fournit l'énergie de base.
- Si une PBS n'est pas alimentée, elle est **hors ligne**.

## Turrets de défense

Les **turrets** sont des tourelles automatiques qui défendent les PBS :

| Turret | Type de dégâts |
|---|---|
| **PBS Turret** | Cinétique |
| **PBS EW Turret** | EM (brouillage) |
| **PBS Laser Turret** | Thermique |
| **PBS Missile Turret** | Explosif |
| **PBS Rail Turret** | Cinétique (longue portée) |
| **Police Guard Tower** | Défense de zone |

## Notes pratiques

- **Les PBS sont des investissements** — elles coûtent cher à déployer.
- **La connexion est cruciale** — une PBS non connectée est inutile.
- **Les turrets défendent** — elles peuvent tuer les robots ennemis.
- **Les territoires se combinent** — plus vous avez de PBS, plus votre zone est contrôlée.
