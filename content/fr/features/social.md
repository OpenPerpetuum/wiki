# Social

La **communication** et la **réputation** sont essentielles dans Open Perpetuum.
Vous interagissez avec d'autres joueurs par la messagerie, le chat, et les standings.

## Messagerie

- **Envoyer** un message à un joueur.
- **Répondre** à un message.
- **Archiver** les messages.
- Les messages sont **stockés** sur le serveur.

## Canaux de chat

Les **canaux de chat** sont des espaces de communication :

| Canal | Description |
|---|---|
| **Local** | Visible par les joueurs dans la même zone |
| **Corporation** | Visible par les membres de votre corporation |
| **Alliance** | Visible par les membres de votre alliance |
| **Bande** | Visible par les membres de votre bande |
| **Privé** | Un-à-un entre deux joueurs |

## Amis

- Vous pouvez **ajouter** des amis.
- Les amis sont **visibles** dans votre liste.
- Vous pouvez **envoyer** des messages directement à vos amis.

## Standings

Les **standings** (réputations) mesurent votre relation avec les factions et les
corporations :

| Standing | Description |
|---|---|
| **Excellent** | 10 000+ |
| **Honneur** | 5 000 – 9 999 |
| **Cordialité** | 1 000 – 4 999 |
| **Neutre** | -999 – 999 |
| **Hostilité** | -4 999 – -1 000 |
| **Haîne** | -9 999 – -5 000 |
| **Détestation** | -10 000+ |

- Les standings **affectent** les prix du marché et les interactions.
- Ils **montent** quand vous faites des actions positives.
- Ils **baissent** quand vous faites des actions négatives.

## Annuaire (pages jaunes)

L'**annuaire** est une liste de joueurs et de corporations :

- Vous pouvez **rechercher** des joueurs par nom.
- Vous pouvez **voir** les corporations et leurs membres.
- L'annuaire est **public** — tout le monde peut le consulter.

## Actualités

Les **actualités** sont des annonces officielles du jeu :

- Mises à jour
- Événements
- Corrections de bugs

## Sondages

Les **sondages** permettent aux joueurs de donner leur avis :

- Les sondages sont **anonymes**.
- Les résultats sont **publiés**.
- Ils aident les développeurs à améliorer le jeu.

## Notes pratiques

- **Les standings comptent** — ils affectent les prix et les interactions.
- **Le chat local** est pour la communication en zone.
- **L'annuaire est public** — ne mettez pas d'informations sensibles.
- **Les messages sont stockés** — pensez-y avant d'écrire.
