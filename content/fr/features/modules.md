# Modules & équipement

Les **modules** sont les composants que vous chargez dans les emplacements de votre
robot. Ils sont organisés en familles.

## Familles de modules

| Famille | Description |
|---|---|
| **Armes** | Projectiles, lasers, missiles, canons à rail |
| **Armure** | Plaques d'armure, réparateurs d'armure |
| **Bouclier** | Générateurs de bouclier, renforts de bouclier |
| **Énergie** | Réacteurs, boosteurs de réacteur, batteries |
| **Électronique** | Capteurs, scanners, stabilisateurs |
| **EWar** | Brouilleurs, masques, amplificateurs |
| **EnWar** | Neutraliseurs, transferts d'énergie, vampires |
| **Industriel** | Mineurs, récolteurs, foreurs |
| **NEXUS** | Modules spéciaux de la faction Nuimqol |
| **NOX** | Modules spéciaux de la faction Pelistal |

## Règles de base

- **Chaque module consomme de l'énergie** — ne surchargez pas votre réacteur.
- **Les modules ont un volume** — ne surchargez pas votre conteneur.
- **La compatibilité est par type** — un module ne peut pas aller dans n'importe quel emplacement.
- **Les modules ont des stats** — dégâts, portée, précision, etc.
- **Les modules ont des résistances** — cinétique, thermique, explosive, EM.

## Équilibrer un robot

Un bon équipement équilibre :

1. **Dégâts** — armes + munitions + modules de dégâts
2. **Défense** — armure + bouclier + réparateurs
3. **Énergie** — réacteur + boosteurs + batteries
4. **Mobilité** — propulseurs + réducteurs de masse
5. **Capteurs** — scanners + capteurs + stabilisateurs

## Notes pratiques

- **Ne surchargez pas l'énergie** — un réacteur en surcharge s'éteint.
- **Les résistances comptent** — adaptez-les à l'ennemi attendu.
- **La portée est cruciale** — un module à courte portée est inutile si vous êtes à longue portée.
- **Les modules T4 sont chers** — ne les engagez pas dans des combats risqués.
