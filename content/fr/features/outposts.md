# Postes avancés & SAP

Les **postes avancés** (outposts) sont des structures que les corporations prennent
et maintiennent dans les zones PvP ouvertes. Ils donnent des **bonus** à la
corporation qui les contrôle.

## Prise d'un poste avancé

1. **Localiser** un poste avancé dans une zone PvP.
2. **Attaquer** les PNJ de défense.
3. **Capturer** le poste (quand les PNJ sont détruits).
4. **Maintenir** le poste (stabilité).

## Stabilité

- Chaque poste a une **stabilité** qui varie de 0 à 100 %.
- Plus la stabilité est élevée, plus le poste est **sûr**.
- Les attaques ennemies **réduisent** la stabilité.
- La stabilité **régénère** avec le temps.

## Types d'activité SAP

Les corporations peuvent effectuer quatre types d'activité SAP sur un poste :

| Type | Description |
|---|---|
| **Production** | Produire des objets au poste |
| **Recherche** | Rechercher des extensions au poste |
| **Extraction** | Extraire des ressources au poste |
| **Défense** | Défendre le poste contre les attaques |

## Bonus des postes avancés

| Bonus | Description |
|---|---|
| **Production gratuite** | Produire sans composants |
| **Recherche accélérée** | Apprendre les extensions plus vite |
| **Ressources bonus** | Obtenir plus de ressources |
| **Territoire** | Contrôler une zone |

## Notes pratiques

- **Les postes avancés sont risqués** — les zones PvP sont dangereuses.
- **La stabilité est cruciale** — maintenez vos postes.
- **Coopérez** — les postes nécessitent plusieurs robots.
- **Les bonus sont permanents** tant que vous contrôlez le poste.
