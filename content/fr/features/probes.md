# Sondes de proximité

Les **sondes de proximité** sont des dispositifs de surveillance que vous pouvez
placer dans une zone pour la surveiller à distance.

## Comment ça marche

1. **Enregistrer** une sonde dans une zone.
2. La sonde **scanne** automatiquement la zone.
3. Vous pouvez **interroger** la sonde pour obtenir les résultats.
4. La sonde **expire** après un certain temps.

## Types de sondes

| Type | Fonction |
|---|---|
| **Surveillance** | Détecte les robots ennemis dans la zone |
| **Minéral** | Détecte les gisements de minerais |
| **Végétation** | Détecte les plantes |
| **Structure** | Détecte les structures (PBS, téléporteurs) |

## Limitations

- Les sondes sont **limitées en nombre** (extension requise).
- Elles **expirent** après un certain temps.
- Elles ne fonctionnent que dans **certaines zones**.
- Les résultats sont **par personnage** (non partagés).

## Notes pratiques

- **Les sondes sont pratiques** pour surveiller une zone sans y être.
- **Elles expirent** — renouvelez-les régulièrement.
- **Le nombre est limité** — utilisez-les judicieusement.
- **Les résultats sont personnels** — partagez-les manuellement si besoin.
