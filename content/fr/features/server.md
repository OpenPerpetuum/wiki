# Serveur & référence

Cette page donne les informations sur le serveur et les ressources de référence.

## Infos serveur

| Info | Valeur |
|---|---|
| **Serveur** | Open Perpetuum (self-hosted) |
| **Base de données** | SQL Server |
| **Client** | Steam (gratuit) |
| **Plateformes** | Windows, Linux (Proton) |

## Scores

Les **scores** (high scores) affichent les joueurs les plus performants :

- Par **credits**
- Par **NIC**
- Par **missions accomplies**
- Par **robots détruits**

## Données de référence

Les **données de référence** sont téléchargeables :

- [Recettes](/content/recipes/) — toutes les recettes de production
- [Minerais](/content/ores/) — toutes les données de minerais
- [Plantes](/content/plants/) — toutes les données de plantes
- [Missions](/content/missions/) — toutes les missions
- [Boutique](/content/shop/) — le catalogue de la boutique

## Boutique in-game

La **boutique in-game** (IHS — In-game Store) est un système d'achat avec de
l'argent réel :

- **EP packs** — des packs d'Energy Points
- **Sparks** — des sparks spéciaux
- **Teintes** — des teintes exclusives
- **Abonnements** — des abonnements mensuels

> **Note** : la boutique in-game est optionnelle. Le jeu est **complet sans achat**
> (free-to-play). L'argent réel achète du confort, pas du pouvoir.

## Notes pratiques

- **Le jeu est gratuit** — pas de pay-to-win.
- **Les données de référence** sont générées depuis la base de données.
- **Les scores** sont mis à jour en temps réel.
- **La boutique** est optionnelle.
