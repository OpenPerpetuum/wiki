# Transport

Le **transport** est le système d'expédition d'objets entre les bases. Les joueurs
postent des conteneurs pour que d'autres joueurs les transportent entre terminaux.

## Comment ça marche

1. **Soumettre** un conteneur à un terminal de transport.
2. Un autre joueur **prend** le conteneur.
3. Le porteur **livre** le conteneur au terminal de destination.
4. Le donneur d'ordre **récupère** le conteneur.
5. Le porteur reçoit sa **récompense**.

## Récompenses & caution

- Le donneur d'ordre définit une **récompense** (crédits) pour le porteur.
- Le porteur mise une **caution** :
  - **Rendue** si le conteneur est livré intact.
  - **Perdue** si le conteneur est détruit.
  - **Moitié rendue** si le porteur abandonne en cours de route.
- Gardez les conteneurs **petits** — quelqu'un doit pouvoir les porter.

## Notes pratiques

- **Le transport est risqué** — les routes sont dangereuses.
- **La caution est perdue** si le conteneur est détruit.
- **Les récompenses doivent être justes** — trop peu et personne ne prend.
- **Escortez vos conteneurs** — les routes sont pleines de pirates.
