# Robot

Votre **robot** est votre avatar en zone. Vous le pilotez à distance depuis votre
base. Cette page couvre la sélection, l'équipement, et la gestion de vos robots.

## Sélectionner un robot actif

- Vous devez avoir un **robot actif sélectionné** pour vous désamarrer.
- Le robot doit avoir l'**extension d'activation** requise pour sa classe.
- Vous pouvez **changer de robot** à tout moment (amarré).

## Équipement (fitting)

L'**équipement** est le processus de charger des modules dans les emplacements de
votre robot. Voir [Équipement](/fr/features/fitting/) pour les détails.

- **Modules** — armes, défense, énergie, électronique, etc.
- **Munitions** — chargées dans les emplacements d'armes.
- **Préréglages** — des configurations sauvegardées que vous pouvez appliquer
  rapidement.
- **Teintes** — la couleur/peinture de votre robot.

## Classes de robots

| Classe | Description |
|---|---|
| **Runner** | Rapide, léger, faible armure |
| **Crawler** | Lourd, lent, bonne armure |
| **Mech** | Équilibré, bon pour le combat |
| **Heavy Mech** | Très lourd, très armé, lent |
| **Walker** | Le plus lourd, le plus armé |

## Gestion des robots

- **Lister vos robots** — voir tous les robots que vous possédez.
- **Renommer** — changer le nom d'un robot.
- **Détruire** — supprimer un robot (irréversible).
- **Transférer** — déplacer un robot d'un personnage à un autre (même compte).

## Notes pratiques

- **N'engagez que ce que vous pouvez remplacer** — un robot mort est perdu.
- **Assurez vos robots chers** — la perte d'un T4 est coûteuse.
- **Les préréglages sont vos amis** — sauvegardez vos configurations.
- **Les teintes sont cosmétiques** — elles ne changent pas les stats.
