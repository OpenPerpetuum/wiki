# Groupes

Les **groupes** sont les structures sociales du jeu : corporations, alliances, et
bandes (flottes).

## Corporations

Une **corporation** est un groupe de joueurs qui partagent :

- Un **hangar** commun (conteneurs partagés)
- Une **cagnotte** (crédits partagés)
- Des **documents** partagés
- Des **votes** pour les décisions importantes

### Rôles

| Rôle | Permissions |
|---|---|
| **Dirigeant** | Tout (gérer la corp, kicker, etc.) |
| **Officier** | Gérer le hangar, la cagnotte, les documents |
| **Membre** | Utiliser les installations de la corp |
| **Invité** | Accès limité (défini par le dirigeant) |

### Adhésion

- Vous pouvez **rejoindre** une corporation par invitation ou en demandant.
- Vous pouvez **quitter** une corporation à tout moment.
- Le dirigeant peut **kicker** un membre.

## Alliances

Une **alliance** est un groupe de corporations qui coopèrent :

- Les membres des corporations alliées peuvent **interagir** plus facilement.
- Les alliances peuvent avoir des **objectifs communs** (territorial, économique).
- Les alliances sont **gérées** par leurs dirigeants.

## Bandes (flottes)

Une **bande** (gang/fleet) est un groupe de joueurs qui se déplacent ensemble :

- Les membres d'une bande peuvent **partager** certaines actions.
- Les bandes sont **temporaires** — elles se dissolvent quand les joueurs se séparent.
- Les bandes sont utiles pour les **combats de flotte** et les **transports escortés**.

## Tableau d'affichage

Le **tableau d'affichage** (bulletin board) est un espace de communication :

- Les joueurs peuvent **poster** des messages.
- Les messages sont **visibles** par tous les membres.
- Les messages peuvent être **catégorisés** (recrutement, commerce, etc.).

## Notes pratiques

- **Rejoignez une corporation** — c'est plus facile en groupe.
- **Les hangars communs** sont pratiques pour le stockage.
- **Les votes** sont pour les décisions importantes.
- **Les bandes sont temporaires** — ne comptez pas dessus en permanence.
