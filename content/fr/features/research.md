# Recherche

La recherche est le système de progression du jeu. Il existe deux arbres :

## L'arbre d'extensions (compétences du personnage)

Les **extensions** sont des compétences passives que votre personnage apprend.
Elles déblorent :

- L'utilisation de certaines classes de robots
- Des bonus passifs (dégâts, défense, vitesse, etc.)
- Des capacités spéciales (téléportation, production, etc.)

Chaque extension a un **coût en EP** (Energy Points) et un **temps d'apprentissage**.
Vous ne pouvez apprendre qu'une extension à la fois.

## L'arbre technologique (déblocages)

L'**arbre technologique** (tech tree) est un système de déblocage d'objets. Vous
achetez des **points de recherche** avec des **kernels** (objets obtenus par des
missions, du marché, ou de la production). Chaque nœud de l'arbre débloque un
objet ou une capacité.

Les catégories de l'arbre technologique :

| Catégorie | Description |
|---|---|
| **Nuimqol** | Recherche pour la faction Nuimqol |
| **Pelistal** | Recherche pour la faction Pelistal |
| **Thelodica** | Recherche pour le clan Thelodica |
| **Commun 1** | Modules standard (premier ensemble) |
| **Commun 2** | Modules standard (deuxième ensemble) |
| **PBS** | Structures de station de base |
| **Industriel** | Recherche industrielle |

## Points de recherche

Les **points de recherche** sont obtenus en dépensant des **kernels** :

- Kernels de mission
- Kernels du marché
- Kernels de production

Chaque nœud de l'arbre a un **coût en points** (variable selon le type : commun,
high-tech, industriel, new-tech, nuimqol, pelistal, thelodica).

## Notes pratiques

- **Planifiez votre recherche** — les extensions et les nœuds de l'arbre
  technologique sont permanents.
- **Les kernels sont rares** — ne les gaspillez pas.
- **La recherche est par personnage** — chaque personnage a son propre arbre.
- **L'arbre technologique est par corporation** — les nœuds déblorent des objets
  disponibles pour toute la corporation.
