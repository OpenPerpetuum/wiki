# Intrusion

Le **mode intrusion** est un système de gameplay où les corporations s'infiltrent
dans des **sites PNJ** pour voler des objets et contrôler le terrain.

## Sites PNJ

Les **sites PNJ** sont des structures avancées dans les zones ouvertes :

- Elles sont **défendues** par des PNJ (turrets, robots).
- Elles contiennent des **objets SAP** (SAP items) de haute valeur.
- Elles ont un **seuil de défense** qui augmente avec le temps.

## Objets SAP

Les **objets SAP** sont des objets de haute valeur trouvés dans les sites :

- Ils sont **très rares** et **très chers**.
- Ils peuvent être **vendus** au marché ou utilisés pour la **production avancée**.
- Ils sont **liés** à la corporation qui les a volés.

## Seuils de défense

- Chaque site a un **seuil de défense** qui augmente avec le temps.
- Plus le seuil est élevé, plus les PNJ sont **nombreux et forts**.
- Les corporations doivent **coopérer** pour surmonter les seuils élevés.

## Améliorations d'installations

- Les corporations peuvent **améliorer** les installations d'un site contrôlé.
- Les améliorations donnent des **bonus de production** et de **recherche**.
- Les améliorations sont **permanentes** tant que la corporation contrôle le site.

## Stabilité

- La **stabilité** d'un site mesure à quel point il est contrôlé.
- Plus la stabilité est élevée, plus le site est **sûr**.
- Les attaques ennemies **réduisent** la stabilité.

## Notes pratiques

- **L'intrusion est risquée** — les sites sont défendus.
- **Coopérez** — les seuils élevés nécessitent plusieurs robots.
- **Les objets SAP sont précieux** — ne les perdez pas.
- **La stabilité est cruciale** — maintenez vos sites.
