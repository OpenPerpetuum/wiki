# 開始

你在 Open Perpetuum 的第一步：建立角色、取得幫助，以及執行客戶端。

- **[快速入門](/zh-TW/features/getting-started/)** — 建立角色、領取初始機器人，以及角色基礎知識。
- **[常見問題](/zh-TW/features/faq/)** — 解答遊戲初期最常見的問題：教學、選擇陣營、訓練完成後該做什麼——以及[術語](/zh-TW/features/faq/)（EP、NIC、CT、EWar）。
- **[世界觀](/zh-TW/features/lore/)** — 背景設定：Nia、Nians、Syndicate。
- **[客戶端與電腦設定](/zh-TW/features/client-setup/)** — 在 Windows 和 Linux 上執行客戶端、規則內的多開、UI 縮放，以及啟動方式。
