# 礦石欄位

礦石透過資料庫中的物種定義。

## 資料欄位

| 欄位 | 類型 | 描述 |
|---|---|---|
| `definition` | int | 定義 ID |
| `definitionname` | string | 定義名稱 |
| `type` | string | 礦石類型（固體、液體） |
| `charge` | # | 礦石電荷（密度） |
| `mass` | # | 礦石質量 |
| `value` | # | 礦石價值 |
